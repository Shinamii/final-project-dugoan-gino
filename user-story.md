# User Stories

### Feature: Order type selection
US1: As a walk-in customer, I want to choose between dine-in and take-out so that my 
order is prepared according to my preference.

US2: As a delivery customer, I want to enter my delivery address so that my order can be 
delivered to the correct location.

US3: As a customer, I want to see my selected order type so that I can verify it before placing my order.

### Feature: Meal customization
US1: As a customer, I want to choose my preferred noodle type so that I can enjoy the 
noodle variety I like.

US2: As a customer, I want to select my preferred spice level so that my meal matches my 
taste.

US3: As a customer, I want to add toppings, drinks, and desserts to my order so that I 
can personalize my meal.

### Feature: Payment Method Selection
US1: As a delivery customer, I want to choose between Cash on Delivery (COD) and online 
payment so that I can pay using my preferred method.

US2: As a walk-in customer, I want to choose between cash and online payment so that I 
can pay conveniently using my preferred method.

US3: As a customer, I want to see my selected payment method in the order summary so 
that I can verify my payment choice before placing my order.
